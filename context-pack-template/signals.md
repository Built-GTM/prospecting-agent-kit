# Signals: when to reach out

*Feeds Why now and the Because. A signal is what has to be true right before they buy. It's not the pitch: mention the signal once, then pivot to the problem it creates.*

*Four types:*
- *Catalyst: an event that makes the problem worse (funding, new leader, hiring spree).*
- *Symptom: public evidence they have the problem (a job post describing the pain, a bad review).*
- *Intent: they're looking for a fix (a competitor's page visit, an RFP, a question in a community).*
- *Absence: something that should be there and isn't (no RevOps hire at 40 reps, no tool in the stack).*
